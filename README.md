## 核心工作流（Stage 0 → Stage 4）

1. **Stage 0 反向挖料门控**：输入过于宽泛时，先抛 3 个锋利问题挖出对象独有怪细节与卡壳场景（提供「按默认假设起跑」快捷出口；局部交付或背景充分时直接推进）。
2. **Stage 1 时代情绪水位与素材矛盾拆解**：区分素材事实 / 可玩之处 / 待验证假设，提炼集体情绪与冲突句 `当___想___，却被___卡住`，拆解同类破圈机制。
3. **Stage 2 三维度现象级核弹切口（双轨门控）**：输出 3 个笑点机制与参与动作截然不同的方向卡（第一眼成品 / 情绪锚点 / 超级模因与谁发给谁 / 二创接口 / 品牌不可替代测试 / 最小验证）。全案态暂停等用户选定（嫌太安全立刻追加第 4 个高冒险反直觉方案）；直出态择优推进。
4. **Stage 3 按需加载单模块交付成品 + 扩散包**：统一按 `[HOOKS]` / `[MAIN_OUTPUT]`（含二创母版与 3 圈层变体）/ `[VIRAL_CLIPS]` / `[COMMENTS]` / `[SPREAD_PATH]` 交付。
5. **Stage 4 五维 10 分制红队审稿与强制重写**：从冷漠年轻人 + 顶级创意总监双视角打分，任意单项 `< 8` 分强制整段推翻重构，交付 5 项均 `≥ 8.5` 分的 2.0 终稿并附诚实的「优点 / 短板 / 验证办法」。
