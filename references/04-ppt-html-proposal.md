# 模块 04：商业提案与竖向滑动 HTML 视听交付规范

> 适用场景：用户要求制作商业全案提案、PPT、比稿 Deck 或竖向滑动 HTML 网页方案时启用本规范。日常写单条梗、脚本或创意卡时无需加载，避免分散注意力。

---

## 1. 形态与阅读体验

- **竖向滑动 PPT 风格 HTML**：默认交付可上下滑动阅读的 **16:9 比例页面流**，标配：
  - 顶部章节导航栏；
  - 滚动阅读进度条；
  - `↑` / `↓` 键盘翻页支持；
  - 点击图片高清放大灯箱；
  - 弹窗内直接播放参考视频（附原链接直达）。
- **多项目独立成册**：若涉及多个商场、品牌或子项目，必须分开撰写独立 HTML 文件，按各自定位与体量定制差异化视觉风格与页数（例如：大型地标或含海外矩阵项目 ≥60 页，常规单项目或社区商业 ≥30 页）。
- **全客群与渠道分灶**：
  - 先核对客群是否完整——例如地标商业必须同时覆盖 **本地日常客 + 国内必去游客 + 海外入境游客**，绝不可漏项；
  - 不同客群、不同平台采用各自原生表达与内容栏目，**不强行套用一个统一大主题或口号**。

---

## 2. 字数黄金区间与标题层级

- **一二三级标题结构（H1 / H2 / H3）**：每页常规内容清晰区分一级标题（核心判断）、二级副标（支撑逻辑）与三级要点（最多 2–4 个短卡片）。标题必须直接表达判断，禁用「核心观点」「主要内容」「项目概述」占位。
- **常规页字数黄金区间（30–48 汉字）**：非豁免的策略、洞察、数据、视觉页，正文汉字严格控制在 **30–48 字**区间——既有清晰信息密度，不为了硬压字数缩成干瘪的 20 字以内短句，也不写成长段落。封面、章节过渡页与封底保持极简视觉冲击力。
- **豁免页不受 48 字上限限制**：以下 5 类落地实操页豁免字数限制，必须交付可直接执行的完整成品：
  1. 完整样稿（图文/公众号/长短文案）；
  2. 海报示意与大字报构图；
  3. 短视频/TVC/MV 完整分镜脚本；
  4. 二创母版包（母版 + 替换槽位 + 3 圈层变体）；
  5. **分阶段标题库**：公众号 / 小红书 / 抖音 / 海外账号等新媒体标题库须按传播阶段或人群拆分，**每阶段输出 3–5 条**有角度差异的标题示意。

---

## 3. 视觉密度与「一图仅用一次」铁律

- **听汇报者是视觉与听觉动物**：全本至少 **85% 以上页面**配备实景图、多图 Moodboard 拼贴墙或参考视频卡片，大幅消除纯文字页。
- **严格零重复铁律**：**一张图仅用一次**——单份提案内严禁同一张图出现在多个页面；多项目并行交付时，**跨方案同样做到零图片重叠**；参考视频同样严禁重复占位。
- **四类高质感多源选图**：
  1. **项目实景图**（用户提供素材包或 Brief 提取图）；
  2. **国际/行业标杆案例截图与 Pinterest 视觉参考墙**；
  3. **定制超逼真摄影级 AI 生图**（严控真实光影、皮肤/建筑/物料质感，杜绝塑料感与廉价促销传单风）；
  4. **轻量动图或定制创意海报示意**。

---

## 4. 参考视频与离线播放规范

- **真视频可试听试看**：针对短视频、海外矩阵（Instagram Reels / TikTok）、快闪造节与线下互动玩法，嵌入真实可播放的参考视频（页内弹窗播放 + 原链接直达），同一支参考视频不重复使用。
- **视频本地化原则**：用户要求离线下载视频时，优先使用 `yt-dlp` 下载 720p MP4 到项目 `assets/videos/`；若遇平台人机登录验证或 IP 拦截，**绝不绕过安全机制**，如实报告并提供用户本机可一键执行的 `--cookies-from-browser` 下载脚本。

---

## 5. 商业保密与去 AI 味红线

- **严禁泄露敏感预算数字**：除非用户明确要求制作报价表，方案正文严禁出现报价、月费、拦标价、刊例费等敏感预算数字。
- **清除 AI 套话**：全本严禁出现「赋能、松弛感、沉浸式体验、匠心打造、美好生活、引爆全网、破局而生、重新定义、价值收割、文化传奇」等空洞宣传腔。

---

## 6. 交付前自动化自检清单（4 项必须通过脚本核验）

生成最终 HTML 提案后，必须运行脚本逐项核验并通过以下 4 项硬指标（与 Stage 4 五维红队审稿同步执行）：

1. **客群完整性核验**：确认已覆盖项目全部核心客群（如地标商业须同时包含**本地高频客 + 国内必去游客 + 海外入境游客**），无漏项、无强行一刀切口号。
2. **媒体零重复 & 零缺失核验**：校验每个 `<img>` 路径真实存在，且在**单本及跨本**中均仅出现 1 次；校验每个参考视频路径/链接无重复嵌入；校验视觉/视频页占比 `≥ 85%`。
3. **字数黄金区间核验**：校验所有非豁免常规策略/洞察/数据页正文汉字稳定落在 **30–48 汉字**区间，且豁免页（样稿/脚本/二创母版/每阶段 3–5 条标题库）内容完整。
4. **敏感词与空话清零核验**：校验无未经要求的报价/月费/拦标价数字，且 AI 套话黑名单命中数为 `0`。
