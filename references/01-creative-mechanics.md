# 模块 01：创意机制、抽象尺度与二创母版规范

> 适用场景：需要拓展抽象脑洞、设计原创梗、校准荒诞尺度，或把一个点子拆成普通人 1 分钟就能改的二创母版包。

---

## 1. 十大创意机制库

这些是生成方法，不是当下流行趋势。根据对象独有资产挑选，必要时组合两种，**绝不逐项套用清单**。新造作品名可以有，解释文字不要堆砌自创概念。

| 机制 | 生成动作 | 常见失败 |
| :--- | :--- | :--- |
| **一本正经地胡说** | 用严肃制度、公文、学术或法庭流程处理一件极小的私事 | 只有公文语气，没有好笑的具体生活事项 |
| **规则错位** | 把场景 A 的完整规则搬进场景 B | 两边没有可一眼理解的对应关系 |
| **物品人格化** | 让物品拥有与其原本功能冲突的真实诉求或脾气 | 只给物品画眼睛、强行卖萌 |
| **低配宏大叙事** | 用极隆重的仪式感、纪录片腔或史诗镜头呈现极有限的成果 | 只喊夸张口号，没有可拍的仪式画面 |
| **字面执行** | 把日常比喻、口头禅或情绪词按字面意思真做出来 | 危险操作，或流于无聊谐音梗 |
| **身份反转** | 让常被评价的一方反过来认真评价评价者 | 强行辱骂用户、冒犯打工人或服务人员 |
| **荒诞但一致的规则** | 先设一个怪前提，后面每一步都严格按它推演 | 每一步随机乱跳，观众抓不住规律无法续写 |
| **熟悉画面的一处偏差** | 保留大众熟悉的画面/句式结构，只换掉 1 个关键角色或目的 | 直接照搬已有作品，缺少对象独有转化 |
| **情绪的实物替身** | 给不可见的小情绪找一个可拍摄、可互动的具体物件 | 变成生硬讲大道理的「情绪价值广告」 |
| **共同续写** | 故意留出命名、角色、结局或评分空位交给观众补完 | 官方把故事讲得太满，观众只剩点赞 |

## 2. 抽象尺度分层（候选方案须体现尺度差异）

- **轻量（全民可秒懂）**：具体生活观察 + 1 处小错位，绝大多数人无需圈内背景知识，看第一眼就懂。
- **中量（规则驱动二创）**：建立一条清晰荒诞规则，观众看完 1 个示例就能举一反三接下去。
- **高量（亚文化 / 圈层核爆）**：依赖圈内语法、反高潮或非线性表达。**必须明确首发小圈层，并附 1 个更容易进入的低门槛版本**，绝不假定「越怪越容易传播」。

用户未指定尺度时，Stage 2 的 3 个核弹方向必须拉开尺度与机制差异：不全做保守谐音，也不全做理解成本极高的怪梗。

## 3. Few-Shot 语感校准（必须对齐 ✅ 的锋利度与真实肌理）

### 案例 A：校园共享洗衣房（虚构创作示范，未经投放验证）
- ❌ **平庸 AI 写法**：「洗出青春，衣起发疯！解锁宿舍松弛感新姿势，和青春烦恼说拜拜，快来参与 #校园洗衣挑战赛 赢取好礼！」（换个产品名放哪都成立，无怪画面、无真实处境、无改写规则。）
- ✅ **现象级方向 1（规则错位 · 图文/海报可改字）**：**洗衣机失物招领处开始招聘袜子**
  - 第一眼画面：一只孤零零的右袜，旁边贴着严肃的人事招聘单，写着：**「急聘左袜一只。搭档已到岗三天。」**
  - 懂的人为什么懂：宿舍洗衣服永远少一只袜子的真实小事，被用极其严肃的 HR 招聘制度处理。
  - 母版与替换槽位：固定 `急聘___。搭档已___`，可替换缺失物和搭档状态；参与者拍自己不成对的物品即可，**无需购买产品或到店**。
  - 三个创作示例（不同圈层）：
    - 同圈自用：「急聘左袜一只。搭档已到岗三天。」
    - 朋友互损：「急聘饭搭子一名。另一位已经端着盘子绕了两圈。」
    - 相邻圈改编：「急聘耳机左耳。右耳宣布不再独唱。」
  - 品牌锚点与取舍：后两条脱离洗衣场景也能玩，跨圈后品牌记忆可能减弱——因此官方提供招聘单视觉底板，袜子原作保留洗衣房辨识，并把「跨圈是否记住品牌」列为首轮验证项。
- ✅ **现象级方向 2（低配宏大叙事 · 短视频观察配字幕）**：**认真观看一场衣服的旋转演出**
  - 第一眼画面：固定机位拍滚筒洗衣机转动，左下角演出字幕：「主演：我的白 T。演出时长还剩 17 分钟。」另一件衣服转到前面时字幕切换：「替补登场。」
  - 差异点：方向 1 靠「拍物品填卡」，方向 2 靠「观察日常循环画面 + 一本正经配演出字幕」，用户可改编到电饭煲、打印机、旋转小火锅（提醒避免拍到陌生人衣物或隐私信息）。

### 案例 B：早八咖啡 / 提神饮品
- ❌ **平庸 AI 写法**：「在这个快节奏的时代，早八打工人的续命神器来了！一杯好咖啡，不仅唤醒你的味蕾，更赋能你的高效一天！」
- ✅ **现象级方向（情绪的实物替身 + 荒诞但一致的规则）**：**《早八清醒度检定报告》杯套**
  - 第一眼画面：咖啡杯套印成冷冰冰的医院体检/设备故障报告——「8:15 检测到宿主灵魂仍在床上；当前咖啡因余额：仅够维持点头微笑，严禁在 10 点前发起脑暴」。
  - 谁发给谁：工位上刚点开早会链接的同事拍杯套发给同组搭子，借它表达「我人到了，但别让我第一个发言」。
  - 品牌不可替代性：杯套刻度随饮品喝掉的高度露出不同状态提示（满杯「请勿搭话」→ 半杯「可聊午餐」→ 见底「已切换下班倒计时」），删掉这杯饮品的物理消耗过程，创意直接失效。

## 4. 二创母版包 5 件套（Stage 3 必交标准）

任何选中方向在 Stage 3 展开时，必须完整交付以下 5 项，严禁只写一句「提供模板供网友二创」：

1. **可直接复制的母版**：写出实际可照抄的句式、画面构图、拍摄动作规则或 15 秒短脚本。
2. **替换槽位与品牌分层**：明确哪些槽位交给用户改、哪 1 个识别锚点要保留；品牌露出分层处理，不强求每次二创都露出全套广告信息。
3. **三个不同圈层的创作示例**：**同圈自用 / 朋友互相调侃 / 相邻圈层改编**各 1 个（必须标注为创作示例，绝不冒充真实网友作品；三条必须在对象或关系上真正不同，不是同义替换）。
4. **真实参与理由 + 低成本版本**：从「炫技能 / 表达态度 / 记录窘境 / 展示审美 / 逗朋友 / 圈内辨认」里选真实匹配的一项（奖品只能助推，不能当唯一理由）；同时提供 **零剪辑、不消费、不到店** 也能参与的截图改字/评论接龙版。
5. **自然续写入口**：留一个可回应的问题、角色空位、可升级的规则或未完情节；绝不伪造错误事实诱导纠错，也不靠虚假争议骗互动。

## 5. 本模块专属红队审查清单（Stage 4 必查）

- 不看后面那段「创意解析」，只看第一眼原文和画面，普通人 3 秒内能笑出来或感受到微妙击中吗？
- 把近期流行热词全部删掉，这个梗本身还能成立吗？
- 三个候选方向是不是真的机制不同、参与动作不同，而不是换了三个名字讲同一件事？
- 三个二创变体是不是真的跨出了不同关系/圈层？普通人看一眼知道自己可以怎么改吗？
