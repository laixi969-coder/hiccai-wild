# 传播与交付

## 全案模式

从受众动作串起传播，不默认每个项目都需要大规模铺量：

1. **起点**：最先看懂的人是谁，在什么具体场景看见？给首发成品、发布主体和渠道选择理由。
2. **第一次参与**：用户看到后如何拿到模板、改出作品、发给谁？用一条完整路径写清楚。
3. **回应**：官方如何接住真实作品或吐槽？给两个回应示例，不预写冒充真实用户的评论。
4. **跨圈**：哪个相邻人群能替换什么元素？保留什么识别点？提供实际变体，不用“破圈”代替方法。
5. **沉淀**：根据目标连接到体验、到店、产品认知、订阅或销售，选适当的一步；纯曝光任务不硬加转化漏斗。

每段说明执行者、素材、时间顺序、成本假设和进入下一段的条件。预算未知时写轻量版本与可加配项，不伪造报价。不未经用户要求发布内容、联系达人或购买流量。

## 平台适配

围绕观看与创作动作改写，同一创意不直接复制到所有平台。以下为设计思路，不是对当前算法的保证：

- 短视频：写开场画面、动作发展、可循环或可回应的结尾，给实际字幕。
- 图文：给封面原文、关键图片内容、可截图改写的母版。
- 长视频或创作者社区：给可延展的设定、素材包、角色或剪辑规则。
- 评论区：设计一句能自然续写的原话及官方接话示例。
- 线下：写清道具、位置、参与动作和拍摄角度，再说明线上用户如何异地参与。

涉及具体平台的现行活动规则、推荐机制或广告要求，先查官方资料；无法证实的建议明确为测试假设。

## 最小验证

先做能区分失败原因的小样，不随意承诺曝光数字。可比较两个开场、两种模板或两档参与成本，一次尽量只改一个关键变量。

根据目标选择少量指标并说明口径：

- 曝光：实际触达与观看情况；区分付费、官方账号和外部传播。
- 分享：分享次数除以所用平台可提供的观看或触达口径，分母前后一致。
- 二创：独立参与人数、合格改编作品数、主动变体类型；排除官方示例和明确的委托作品，或单独列出。
- 品牌连接：评论中自然提及、简单回访问答或可追踪体验入口。不能把所有浏览自动归因为品牌记忆。
- 商业动作：以实际可追踪的点击、预约或购买衡量，说明归因限制。

阈值优先参考用户历史基线或本次对照组。无基线时把首轮作为基线建立，不杜撰行业标准。样本小、分发量悬殊或投放不同则不草率下结论。

用观察决定修改：看懂但不分享，检查关系表达；有人点赞没人改，降低制作成本并示范；二创多却忘记品牌，加强可保留的原生资产；误读和投诉出现，先确认具体原因，再修改或停止对应版本。

## PPT 与竖向滑动 HTML 视听交付模式

用户要求制作 PPT、商业全案或网页提案时启用本规范：

### 1. 形态与阅读体验
- **竖向滑动 PPT 风格 HTML**：默认交付可上下滑动阅读的 16:9 比例页面流，配顶部章节导航、滚动阅读进度条、`↑↓` 键盘翻页、点击图片高清放大与弹窗内直接播放参考视频。
- **多项目独立成册**：若涉及多个商场/品牌/子项目，必须分开撰写独立 HTML 文件，按各自定位与体量定制差异化视觉风格与页数（例如大型地标或含海外矩阵项目 ≥60 页，常规单项目/社区商业 ≥30 页）。
- **分渠道不强行统一主题**：不同客群、不同平台采用各自原生表达与内容栏目，不强行套用一个统一大主题或口号。

### 2. 字数黄金区间与标题层级
- **一二三级标题结构**：每页常规内容清晰区分一级标题（核心判断）、二级副标（支撑逻辑）与三级要点（最多 2–4 个短卡片），标题直接表达判断，不用“核心观点”“主要内容”占位。
- **常规页字数校准（30–48 汉字）**：非豁免的策略、洞察、数据、视觉页，正文汉字控制在 **30–48 字**区间——既保持大屏一眼可读，又避免机械压到 20 字以内显得空洞干瘪。封面、章节过渡页与封底保持极简冲击力。
- **豁免页不受字数限制**：涉及**完整样稿、海报示意、短视频分镜脚本、二创母版、分阶段标题库**的页面豁免 48 字上限，须给出可直接落地的完整成品；其中公众号/小红书/抖音/海外账号等新媒体标题库须按阶段或人群拆分，**每阶段输出 3–5 条**有角度差异的标题示意。

### 3. 视觉与「一图仅用一次」铁律
- **高视觉密度**：听汇报的人是视觉动物和听觉动物，全本至少 **85% 以上页面**配备实景图、多图 Moodboard 拼贴墙或参考视频卡片，大幅消除纯文字页。
- **严格零重复**：**一张图仅用一次**——单份提案内严禁同一张图出现在多个页面；多项目并行交付时，跨方案同样做到零图片重叠。
- **多源超质感选图**：优先组合使用四类高质感素材：① 项目实景图（用户提供素材包或 Brief 提取图）；② 国际/行业标杆案例截图与 Pinterest 视觉参考墙；③ 定制超逼真质感摄影级 AI 生图（严控真实光影与材质，杜绝塑料感与廉价促销传单风）；④ 轻量动图或定制创意海报。

### 4. 参考视频与离线播放
- **真视频可试听试看**：针对短视频、海外矩阵（Instagram Reels / TikTok）、快闪造节与线下互动玩法，嵌入真实可播放的参考视频（页内弹窗播放 + 原链接直达），同一支参考视频不重复占位。
- **视频本地化原则**：用户要求离线下载视频时，优先使用 `yt-dlp` 下载 720p MP4 到项目 `assets/videos/`；若遇平台人机登录验证或 IP 拦截，绝不绕过安全机制，应如实报告并提供用户本机可一键执行的 `--cookies-from-browser` 下载脚本。

### 5. 交付前自动化自检清单
生成最终 HTML 提案后，必须通过脚本逐项核验：
1. **客群完整性**：是否覆盖项目全部核心客群（如地标商业是否兼顾**本地高频客 + 国内必去游客 + 海外入境游客**）。
2. **图片零重复 & 零缺失**：校验每张 `<img>` 路径存在且在单本及跨本中均仅出现 1 次；校验参考视频无重复嵌入。
3. **字数区间达标**：校验所有非豁免常规策略页稳定落在 30–48 汉字区间。
4. **敏感词与空话清零**：除非用户明确要求写报价单，严禁出现报价/月费/拦标价数字；清除“赋能、松弛感、沉浸式体验、匠心打造、美好生活、引爆全网”等 AI 套话。
