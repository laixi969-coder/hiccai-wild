# 创意机制与示例

这些是生成方法，不是当下流行趋势。根据对象选择，必要时组合两种，不把清单逐项套用。新造的作品名称可以有，解释文字不要堆自创概念。

| 机制 | 生成动作 | 常见失败 |
| --- | --- | --- |
| 一本正经地胡说 | 用严肃制度处理一件极小的私事 | 只有公文语气，没有好笑的具体事项 |
| 规则错位 | 把场景A的完整规则搬进场景B | 两边没有可理解的对应关系 |
| 物品人格化 | 让物品拥有与其功能冲突的诉求 | 只给物品加眼睛、卖萌 |
| 低配宏大叙事 | 用极隆重的方式呈现极有限的成果 | 只喊夸张口号，没有仪式画面 |
| 字面执行 | 把日常比喻真的做出来 | 危险操作或无聊谐音 |
| 身份反转 | 让常被评价的一方评价评价者 | 强行辱骂用户或工作人员 |
| 荒诞但一致的规则 | 先设一个怪前提，再严格遵守 | 每一步随机，观众无法续写 |
| 熟悉画面的一处偏差 | 保留熟悉结构，只改关键角色或目的 | 直接照搬已有作品，缺少转化 |
| 情绪的实物替身 | 给不可见的小情绪一个可拍摄物件 | 变成生硬的情绪价值广告 |
| 共同续写 | 留出命名、角色、结局或评分空间 | 官方已经把故事讲完，只剩点赞 |

## 抽象尺度

- **轻量**：生活观察加一个错位，大多数人无需背景知识。
- **中量**：建立荒诞规则，观众看完示例就会接。
- **高量**：依赖圈内语法、反高潮或非线性表达。明确首发小圈层，附一个更容易进入的版本，不假定越怪越容易传播。

用户未指定时，让候选方案体现尺度差异，不全做保守谐音，也不全做理解成本很高的怪梗。

## 示范：校园共享洗衣房

以下均为虚构创作示范，未经投放验证；不是热点案例，不应机械复用。

**平庸方向**：“洗出青春，衣起发疯。”换个名词几乎适配任何产品，没有值得拍的画面，也没有可改的规则。

**方向一：洗衣机失物招领处开始招聘袜子**

第一张卡写：“急聘左袜一只。搭档已到岗三天。”画面是一只孤零零的右袜，旁边贴招聘单。

笑点来自袜子失散的真实小事被当成人事问题处理。母版保留“急聘___。搭档已___”，可替换缺失物和搭档状态。参与者拍自己的不成对物品即可，不需要购买。

- 同圈：“急聘左袜一只。搭档已到岗三天。”
- 朋友：“急聘饭搭子一名。另一位已经端着盘子绕了两圈。”
- 相邻圈：“急聘耳机左耳。右耳宣布不再独唱。”

后两条保持招聘式寻搭档的规则，允许脱离洗衣场景；品牌可提供招聘单视觉底板，袜子原作保留洗衣房辨识。跨圈后的品牌记忆可能减弱，需要验证，不能假定所有二创都会导流。

**方向二：认真观看一场衣服的旋转演出**

固定机位拍洗衣机转动，角落字幕：“主演：我的白T。演出时长还剩17分钟。”另一件衣服转到前面时改字幕：“替补登场。”

这里依靠观看方式错位而非句式。母版为“一个日常循环画面＋一本正经的演出字幕”，用户可改成电饭煲、打印机等，避免拍到陌生人的衣物或个人信息。验证重点是观众会不会给自己的日常物件配字幕，而非只觉得原片可爱。

这两个方向的差别在参与动作：一个拍物品填卡，一个观察循环动作配字幕。不能只换活动名，声称有两个创意。
